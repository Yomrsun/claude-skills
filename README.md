## Install

**Claude.ai or the Claude desktop app**

1. Download the skill's .zip from the table above.
2. Make sure code execution is turned on in Settings. Skills need it.
3. Go to **Customize > Skills** ([claude.ai/customize/skills](https://claude.ai/customize/skills)), upload the .zip and turn the skill on.
4. Ask for it:
   - "Audit this before I post: [paste]"
   - "Make a story bible for my book" (attach your draft if you have one)
   - "Run the reader panel on this chapter: [paste]"

**Claude Code**

Copy a folder from [`skills/`](skills/) into `~/.claude/skills/`, so the file sits at `~/.claude/skills/pre-publish-audit/SKILL.md`. Start a new session and ask for it.

**Tip for the audit:** run it in a different chat from the one that wrote the copy. A fresh read checks what the copy says, not what you meant.
